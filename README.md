# TextEx

TextEx is a Windows desktop application that extracts text directly from the screen and translates it instantly.

Built with Python and PyQt6, it combines screen capture, OCR, translation, clipboard integration, and history tracking into a lightweight workflow designed for quick text extraction from images, videos, documents, and applications.

## Features

* Capture text from any area of the screen
* OCR-powered text recognition
* Instant translation into multiple languages
* Overlay results without interrupting workflow
* Clipboard integration for quick copying
* Translation and OCR history
* Global hotkeys for fast access
* Windows system tray support

## Installation

Download the latest release from the Releases section and run the installer.

## Requirements

* Windows 10 or Windows 11

## Project Structure

core/ - application logic

services/ - OCR, translation, capture, clipboard, and export services

ui/ - user interface components

database/ - local history storage

installer/ - Inno Setup installer configuration
